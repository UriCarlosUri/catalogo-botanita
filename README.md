# 🥜 BOTANITA — Catálogo Digital & Menú Interactivo

Aplicación web frontend ligera, responsiva y optimizada para móviles diseñada para la visualización dinámica del catálogo de productos y lista de precios de la marca **BOTANITA**. El proyecto incluye navegación anclada por categorías, sistema de búsqueda y filtrado en tiempo real en Vanilla JavaScript, y despliegue continuo a través de GitHub Pages vinculado a códigos QR para empaques y puntos de venta.

## ✨ Características Principales

- **Filtro y Búsqueda en Tiempo Real:** Filtrado dinámico instantáneo por nombre o ingrediente sin recarga de página.
- **Navegación Fluida (Smooth Scroll):** Barra de categorías fija (*sticky navigation*) con desplazamiento asistido a cada sección.
- **Identidad de Marca & UI/UX Fiel:** Paleta cromática oficial, cenefas con patrones basados en el empaque flexográfico y logotipo de la marca.
- **Mobile-First & 100% Responsivo:** Adaptado ergonómicamente para consulta rápida desde smartphones mediante escaneo QR.
- **Acceso Directo a Canales de Venta:** Integración con API de WhatsApp para pedidos directos y enlace geolocalizado a Google Maps.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura accesible y modular.
- **CSS3 Moderno:** Variables CSS (Custom Properties), CSS Grid, Flexbox, animaciones de transición y pseudo-clases.
- **JavaScript (Vanilla ES6+):** Manipulación dinámica del DOM, listeners de eventos para búsqueda en vivo y control de visibilidad de secciones.
- **GitHub Pages:** Despliegue y alojamiento estático continuo.
